⚽ About Matchday Sports Hub

Matchday Sports Hub is a high-performance web dashboard built to give football enthusiasts real-time access to match fixtures, team crests, venue locations, and league table standings across Europe's top leagues.

Developed with HTML5, Bootstrap 5, and Vanilla ES6 JavaScript for maximum speed and zero third-party framework overhead.

⚙️ How It Works
  1. Filter by League: Select your preferred league from the dropdown to fetch matching fixtures dynamically.
  2. Search Teams: Type any club name into the search bar for instant real-time client-side filtering.
  3. Status Filter: Toggle between Finished (FT) and Upcoming (NS) matches.
  4. View Standings: Click "View Standings" to inspect full points, goal differences, and league table rankings.
